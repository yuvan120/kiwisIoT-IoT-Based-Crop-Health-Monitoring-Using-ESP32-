# kiwisIoT-IoT-Based-Crop-Health-Monitoring-Using-ESP32-

## 📌 About the Project

IoT-Based Crop Health Monitoring Using ESP32 with KiwisIoT is a smart agriculture project designed to monitor crop-growing conditions and support better crop management.

Using the ESP32 microcontroller and connected sensors, the system collects real-time environmental and soil data such as soil moisture, temperature, humidity, and other important parameters that affect crop growth.

The collected sensor data is transmitted through Wi-Fi to the KiwisIoT platform, where farmers and users can visualize and monitor crop-growing conditions through an online dashboard from anywhere.

By continuously monitoring environmental conditions, this project helps identify unsuitable growing conditions, supports early detection of potential crop-related problems, and helps farmers make better agricultural decisions.

This project demonstrates how Internet of Things (IoT) technology can be used to improve crop monitoring, support smart farming, and promote modern agricultural practices.
